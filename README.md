# Nocturne Reader

Nocturne Reader is a Safari extension designed to provide a comfortable dark reading experience for websites.

## How to Use

1. Install Nocturne Reader from the Mac App Store.
2. Open the Nocturne Reader app.
3. Click **Open Safari Extensions**.
4. Enable **Nocturne Reader** in Safari → Settings → Extensions.
5. Click the Nocturne Reader toolbar icon to turn Dark Mode on or off.

## Support

If you experience any issues or have suggestions, please use the **Issues** section of this GitHub repository.

## Privacy
Nocturne Reader does not collect, store, or sell personal information.
