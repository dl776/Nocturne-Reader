# NightSafari Reader

NightSafari Reader is a Safari extension designed to provide a comfortable dark reading experience for websites.

## How to Use

1. Install NightSafari Reader from the Mac App Store.
2. Open the NightSafari app.
3. Click **Open Safari Extensions**.
4. Enable **NightSafari** in Safari → Settings → Extensions.
5. Click the NightSafari toolbar icon to turn Dark Mode on or off.
